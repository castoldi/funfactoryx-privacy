Privacy Policy — YouTube Shorts Creator

Effective date: November 11, 2026

What this application is

YouTube Shorts Creator is a private, single-user tool operated by the owner of the YouTube channel FunFactoryXCurioSprints. It is not a public service and has no users other than the channel owner. Its only function is to upload videos prepared by the owner to the owner's own YouTube channel through the YouTube Data API v3.

Information the application accesses

  • Google account authorization. The application requests a single OAuth permission: youtube.upload — the ability to upload videos to the owner's channel. It does not request access to email, contacts, files, or any other Google service.
  • Video files and metadata. The video files, titles, descriptions, and tags that the owner prepares for upload. This content is created by the owner; the application only transmits it to YouTube.

The application does not collect analytics, does not read comments, subscriptions, or viewing history, and does not track anyone.

How the information is used

Solely to upload the owner's videos to the owner's own YouTube channel, as instructed by the owner. Nothing else.

Storage and security

The OAuth access and refresh tokens, together with the application's client credentials, are stored locally on the owner's own computers, in files whose permissions are restricted to the owner. They are never committed to a public repository and are never transmitted to any party other than Google.

Sharing

No data is sold, rented, or shared with third parties. The only external communication is with Google's and YouTube's own APIs, to perform the uploads the owner requested.

Google API Services User Data Policy

This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

The owner can revoke the application's access at any time from Google Account permissions. Revoking access immediately stops the application from uploading. The locally stored tokens can be deleted at any time by deleting the token file; no copy exists anywhere else.

Changes to this policy

If this policy changes, the updated version will be posted at this same URL with a new effective date.
